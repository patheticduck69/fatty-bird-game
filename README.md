## 🤔 What is this?

Remember Flappy Bird? One bird. One button. Pipes. Rage.

**Fatty Bird** keeps the rage and fixes the "only one bird" problem. It is a free, pixel-art browser game with more characters, more skills, more ways to fail, and a cave. Yes, a cave. With a dragon. You'll see.

> *Open the link, tap, and you're flying in seconds.*

## 🎮 Controls

| Input | Action |
|:--|:--|
| **Tap / Click / Space** | Flap |
| **E** | Character skill |
| **Q** · **W** · **S** | Pulse · Blink · Shield |
| **Pause button** | Takes a breath for you |

Don't touch the pipes. Don't touch the ground. Everything else is a suggestion.

## 🚀 Run it yourself

```bash
git clone https://github.com/patheticduck69/fatty-bird-game.git
cd fatty-bird-game

# any simple web server works, for example:
python3 -m http.server 8000
# then open http://localhost:8000
```

Using a local server (instead of double-clicking the file) lets the animated backgrounds and sounds load properly.

**Host your own copy:** fork this repo, then go to *Settings → Pages* and choose your branch.
